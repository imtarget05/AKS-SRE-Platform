Kubernetes Probe Split Pattern (Anti-Cascading Restarts)

Minh chứng quy chuẩn kiến trúc SRE: Phân lập tuyệt đối giữa /health/live (kiểm tra event loop) và /health/ready (phụ thuộc downstream). Khi dependency chết, Service cô lập traffic với 0 lần restart pod.

GET /health/live HTTP 200 OK

Trả lời câu hỏi "Event loop Node.js có còn sống không?". KHÔNG BAO GIỜ chạm database hay dependency. Nếu dependency chậm hoặc sập, probe này vẫn khỏe mạnh, chặn đứng vòng xoáy CrashLoopBackOff!

{ "status": "live", "uptime_s": 1420.8 }
GET /health/ready HTTP 200 READY

Trả lời câu hỏi "Pod này có nên nhận traffic không?". CÓ phụ thuộc downstream. Khi dependency chết, Service gỡ endpoint khỏi kube-proxy với 0 LẦN RESTART.

{ "status": "ready", "dependency": true }

Thao tác mô phỏng Probe Sandbox (Đồng bộ toàn hệ thống):

HTTP/1.1 200 OK • {"route":"/internal/readiness","ready":true} • Endpoint active in kube-proxy
